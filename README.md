# Automação E2E - Sauce Demo

Primeiro projeto de automação de testes end-to-end do site [Sauce Demo](https://www.saucedemo.com), feito com Playwright e JavaScript.

## Tecnologias
- Playwright
- JavaScript (Node.js)
- GitHub Actions

## Cenários automatizados
- Compra de ponta a ponta com sucesso
- Login com senha inválida exibe mensagem de erro

## Como rodar o projeto
```bash
git clone https://github.com/MarcioGuerra1/automacao-saucedemo-playwright.git
cd automacao-saucedemo-playwright
npm install
npx playwright install
npx playwright test
```
